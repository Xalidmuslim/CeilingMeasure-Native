# Arabic Grammar — Хайбуллин

Отдельное Android-приложение без Floot и без PDF-ридера.

## Архитектура

- Android WebView используется только как локальная оболочка для HTML/CSS/JS, встроенных в APK.
- В рантайме книга не загружается из интернета: content.json помещается в android_asset при сборке.
- Арабский хранится как Unicode-текст с огласовками, а не как OCR из PDF.
- На главном экране системная кнопка/жест Back не закрывает приложение; внутри приложения возвращает на предыдущий экран.
- Прогресс, закладки, заметки и настройки хранятся локально.

## Источники контента

1. Пользовательская PDF-копия книги используется как эталон структуры и состава разделов.
2. Для арабского Unicode применяется открытая HTML-копия книги на Studopedia (37 последовательных страниц статьи).
3. Наличие того же издания дополнительно подтверждается открытой PDF-копией Quran Academy.

Скрипт scripts/fetch-book.mjs скачивает 37 страниц, сохраняет текст без PDF, проверяет объём арабского Unicode и отсутствие явных ошибок кодировки, затем формирует app/src/main/assets/book/content.json.

## Сборка

GitHub Actions workflow автоматически:
1. получает и проверяет полный текст;
2. сохраняет снимок content.json в ветке, если GitHub разрешает запись;
3. собирает APK;
4. прикладывает APK и audit JSON как artifacts.
