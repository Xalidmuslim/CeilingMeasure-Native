ТРЕБОВАНИЕ К ИСПРАВЛЕНИЮ
Сделай минимальную compatibility-реализацию без redesign drawing engine.

Допустимы только изменения, прямо необходимые для корректного смысла persisted labelPose.

Source-of-truth behavior:
- если manual=true и finite persisted labelPose.x/y существуют, native resolved label center должен быть ровно x/y в world coordinates, независимо от auto placement;
- если manual pose отсутствует, текущий auto-placement behavior не менять;
- angle normalize и size clamp оставить по audited contract;
- export после import без пользовательского редактирования обязан вернуть те же semantic x/y;
- edge и diagonal должны вести себя одинаково;
- unknown-compatible fields labelPose должны сохраняться.

Не выбирай решение, которое зависит от конкретного viewport, density или текущего zoom при десериализации.
Нельзя при чтении backup вычислять offset от auto placement, если для этого требуется UI/device state.

Предпочтительное минимальное направление:
- хранить persisted absolute labelX/labelY как absolute truth;
- label placement layer при manual absolute pose использует exact labelX/labelY вместо auto+offset;
- существующий offset path остаётся для старого native runtime state только там, где absolute pose реально отсутствует.

Если для корректного изменения уже импортированной manual label при drag требуется минимальный compatibility hook в drawing layer, допускается изменить ТОЛЬКО label-coordinate update path. Не менять hit thresholds, gesture timing, rotate UI, size UI или visual placement algorithm.
