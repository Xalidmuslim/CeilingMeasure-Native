# CeilingMeasure-Native

Android/APK packaging repository for the ceiling measurement application.

## Golden master
The browser application is preserved as the golden master and must not be redesigned or rewritten during APK packaging.

Before making Android changes, read:
- `FEATURE_CONTRACT.md`
- `ASTRA_MAX_APK_COMMAND.txt`
- `golden_master/README.md`

The APK task is packaging + regression verification, not a native rewrite.
