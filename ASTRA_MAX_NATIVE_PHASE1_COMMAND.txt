TEST PHILOSOPHY
Нельзя тестировать только «объект сериализуется».
Нужны golden-compatible deep comparisons.

Для каждого fixture:
source JSON → native parse/migrate → native serialize/export → compare canonical semantic result с ожидаемым v184 contract.

Если порядок JSON keys отличается — это допустимо.
Если значения, defaults, arrays, ids, field presence или migration meaning отличаются — FAIL.
