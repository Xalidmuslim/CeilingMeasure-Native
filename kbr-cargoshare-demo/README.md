# ГрузШер КБР — Android offline demo APK
Это самостоятельный установочный Kotlin + Jetpack Compose APK для ознакомления с интерфейсом.
Три условных грузовых автомобиля, выбор 2/4/8/24 часов, расчёт демонстрационной стоимости, локальные тестовые заявки и профиль.
Работает на телефоне **без сервера**. Никакие данные не отправляются. Не реализованы реальные платежи, проверка документов, юридически значимые действия, сохранение бронирований на сервере и редактирование автопарка из админ-панели.
Это **preview-сборка** для проверки дизайна и навигации. Исходный прототип 0.2 с серверным редактированием предоставлен отдельно в чате.
Код находится в папке android/. Автоматическая сборка в Actions на ветке codex/kbr-cargoshare-android-apk-20261017.
