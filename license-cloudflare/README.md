# CeilingMeasure v225 — бесплатный сервер лицензий без email

**Статус:** исходный код подготовлен в отдельной ветке. Не развёрнут на Cloudflare. Не принимает реальные платежи.

## Архитектура

- Android: полностью нативное приложение Java, без WebView.
- Cloudflare Workers Free: API проверки лицензий, штатный бесплатный адрес `*.workers.dev`.
- Cloudflare D1 Free: дата начала 7-дневного пробного доступа, пользователи, платежные лицензии.
- **Без электронной почты, SMS, SMTP и собственного домена.**
- При первом подключении Android создаёт анонимный аккаунт; Worker выдаёт 256-битный секретный код восстановления (`cm1_...`).
- Код показывается пользователю и хранится внутри Android-приложения. После смены телефона пользователь восстанавливает право доступа этим кодом.
- Подписанные RSA SHA256 лицензии допускают работу офлайн до 14 суток, но не дольше даты окончания подписки или пробного срока.
- Без платежного провайдера администратор вручную зачисляет подтвержденную месячную или бессрочную лицензию по идентификатору покупателя.
- Cloudflare НЕ является кошельком и НЕ принимает платежи.

## Первое развёртывание

Нужен аккаунт Cloudflare, установленный Node.js для CLI и Wrangler (все команды выполняются в папке `license-cloudflare`). Собственный домен не нужен.

1. Выполнить `npx wrangler login`.
2. Создать базу: `npx wrangler d1 create ceilingmeasure-licenses`.
3. Скопировать `database_id` из ответа в `wrangler.toml`, заменив `REPLACE_WITH_ACTUAL_D1_DATABASE_ID`.
4. Применить схему: `npx wrangler d1 migrations apply ceilingmeasure-licenses --remote`.
5. Сгенерировать RSA ключ **локально**, никогда не загружать приватный ключ в GitHub:

   ```bash
   openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out private.pem
   openssl pkcs8 -topk8 -nocrypt -in private.pem -outform DER | base64 | tr -d '\n'
   openssl pkey -in private.pem -pubout -outform DER | base64 | tr -d '\n'
   ```

   Первый base64 — приватный PKCS8 DER, хранится только в Worker secret под названием `LICENSE_PRIVATE_KEY_PKCS8_B64`.
   Второй base64 — публичный SPKI DER для параметра Android `CEILING_LICENSE_PUBLIC_KEY_B64`.

6. Сохранить 3 секрета Cloudflare (команда запросит значение и не вставит его в исходный код):

   ```bash
   npx wrangler secret put LICENSE_PRIVATE_KEY_PKCS8_B64
   npx wrangler secret put ADMIN_API_KEY
   npx wrangler secret put IP_HASH_PEPPER
   ```

   `ADMIN_API_KEY` и `IP_HASH_PEPPER` должны быть разными случайными строками длиной минимум 32 символа. Генерация: `openssl rand -hex 32`.

7. Развернуть: `npx wrangler deploy`. Wrangler выдаст адрес вида `https://ceilingmeasure-license.<account>.workers.dev`.
8. Проверить `https://<hostname>/health` — должен вернуться `{"status":"ok"}`.

Перед первым боевым использованием настроить регулярное резервное копирование D1, ограничения частоты запросов, оповещения о сбоях и проверку безопасности.

## Android APK

**Без параметров сервера** сборка v225 работает в режиме наследованного бесплатного доступа, чтобы не блокировать владельцев v224 случайно.

Для пробной версии с реальным сервером собирать с двумя параметрами:

```bash
gradle assembleRelease \
  -PceilingLicenseUrl=https://YOUR_SUBDOMAIN.workers.dev \
  -PceilingLicensePublicKeyB64=BASE64_SPKI_PUBLIC_KEY
```

Публичный ключ можно встраивать в APK; приватный — никогда. После этого пользователь нажимает «Начать 7 дней бесплатно», сохраняет код и работает.

## API (платёжные реквизиты не сохраняются)

- `POST /v1/auth/register`: `{"device_id":"32_character_random_device_id"}`, выдаёт `recovery_code`, `user_id` и подписанную лицензию; запускает 7 дней.
- `POST /v1/auth/recover`: `{"device_id":"...", "recovery_code":"cm1_..."}`, восстанавливает тот же аккаунт, без нового триала.
- `POST /v1/license`: тело `{"device_id":"..."}`, заголовок `Authorization: Bearer cm1_...`, обновляет подписанную лицензию.
- `POST /v1/admin/grants`: `X-Admin-Key: <SECRET>`, тело `{"user_id":"UUID","kind":"monthly","source":"manual","external_ref":"sale_000001","paid_until":"2026-12-01T00:00:00Z"}`. Бессрочный доступ: `"kind":"lifetime"` без `paid_until`.
- `POST /v1/admin/revoke`: `X-Admin-Key: <SECRET>`, тело `{"external_ref":"sale_000001"}`.

Администратор может вносить лицензию только после реального подтверждения оплаты. Повторное использование `external_ref` блокируется на уровне D1.

## Ограничения и условия коммерческого запуска

1. **Никакая платёжная система не подключена**: россияне ещё не могут оплачивать рублёвыми картами через этот backend. Требуется договор с платёжной платформой и проверка webhook подписи либо ручное подтверждение каждой оплаты.
2. Отсутствие регистрации означает отсутствие доказанной личности. Очищение данных и новый аккаунт потенциально позволяют повторять триал; сервер ограничивает регистрации с одного IP (5 за сутки), что не даёт полной защиты и может затронуть людей на общем Wi-Fi.
3. Код восстановления — эквивалент пароля! Если его украдут, покупку можно восстановить на другом телефоне. Сохранять секрет вне публичных чатов.
4. Возвраты/отзывы лицензий станут видимы на телефоне после следующей проверки, максимум 14 дней при отсутствии сети.
5. Перед размещением платёжных функций необходимо согласовать право продавца распространять приложение, налоговый режим и правила выбранной платформы.
6. Старые пользователи v224 требуют отдельного решения о бесплатном доступе при переходе на коммерческий APK.
7. Для коммерческого выпуска проверять Android-билд, тесты Worker и целостность данных v224; не выдавать preview APK за финальную.
