# Замер потолка v226 — оплата переводом + WhatsApp + ручное лицензирование

**Статус:** исходный код подготовлен в отдельной ветке `feature/manual-whatsapp-v226`. Сервер **не размещён**, реальный номер WhatsApp **не указан**, APK **не собран и не протестирован как релиз**. Исходная нативная v224 остаётся без изменений.

## Как будет работать

1. Покупатель устанавливает APK. Приложение при первом запуске пытается автоматически зарегистрировать **7 дней бесплатного доступа** на сервере, без email, телефона, SMS и паролей. Первый запуск требует интернета.
2. Покупатель открывает «Лицензия» → «Связаться с продавцом / купить доступ».
3. Выбирает «30 дней — 299 ₽» или «Навсегда — 2 990 ₽». Это стартовые цены в настройках, владелец может их изменить.
4. Нажимает «Написать в WhatsApp»: открывается чат с номером владельца и **заранее подготовленным сообщением**, содержащим только вариант лицензии и публичный ID покупателя.
5. Владелец сообщает клиенту реквизиты для законного перевода. Приложение **не хранит номер карты или платёжные данные**.
6. Владелец убеждается, что деньги **действительно поступили в его банковское приложение**. Никакая фотография перевода или сообщение клиента не подтверждают оплату.
7. Владелец открывает **в том же Android-приложении** раздел «Лицензия» → «Режим владельца», вводит секретный `ADMIN_API_KEY`, ID клиента и уникальный номер банковского перевода, выбирает 30 дней или «Навсегда».
8. Сервер подтверждает права администратора, записывает лицензию и запрещает повторное использование того же номера перевода.
9. Клиент нажимает «Обновить лицензию». После проверки подписанной лицензии приложение предоставляет оплаченный доступ.
10. После следующего продления на 30 дней срок прибавляется к ещё действующему оплаченному периоду, не обнуляя оставшиеся дни.

**Нет платёжного сервиса, API банка, рекуррентных списаний, электронной почты и комиссии платформы.** Учёт дохода, оформление отношений с покупателем, обязательные чеки и налоги всё равно требуют соблюдения применимых правил.

## Связь с клиентами из России

В феврале 2026 года WhatsApp был заблокирован в России; даже при корректной ссылке `wa.me` он может не работать у клиента. Поэтому рядом с кнопкой WhatsApp есть «Позвонить продавцу»: используется тот же номер либо отдельно заданный резервный контакт. Прежде чем делать платную продажу, проверьте работу связи на реальных российских телефонах. Подтверждение: https://www.reuters.com/technology/russia-blocks-metas-whatsapp-messaging-service-ft-reports-2026-02-12/

Покупатель **не должен сообщать** код восстановления. Продавцу достаточно публичного ID.

## Cloudflare Worker и D1

Бэкенд написан без сторонних Node-зависимостей для Cloudflare Workers/D1. Для бесплатной базы и адреса `*.workers.dev` нужен собственный аккаунт Cloudflare. Работоспособность `workers.dev` из российских сетей **не гарантирована**; предварительное тестирование на мобильных операторах обязательно.

Порядок настройки:

```bash
cd license-cloudflare
npx wrangler login
npx wrangler d1 create ceilingmeasure-licenses
```

Вставить созданный `database_id` в `wrangler.toml` вместо `REPLACE_WITH_ACTUAL_D1_DATABASE_ID`.

```bash
npx wrangler d1 migrations apply ceilingmeasure-licenses --remote
openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out private.pem
openssl pkcs8 -topk8 -nocrypt -in private.pem -outform DER | base64 | tr -d '\n'
openssl pkey -in private.pem -pubout -outform DER | base64 | tr -d '\n'
```

Первый base64 от private.pem — приватный PKCS8 DER для Worker secret `LICENSE_PRIVATE_KEY_PKCS8_B64`. Второй — публичный SPKI DER для APK, это **не секрет**. **Никогда не загружать private.pem и пароль администратора в GitHub или APK!**

```bash
npx wrangler secret put LICENSE_PRIVATE_KEY_PKCS8_B64
npx wrangler secret put ADMIN_API_KEY
npx wrangler secret put IP_HASH_PEPPER
npx wrangler deploy
```

Два последних значения — независимые случайные строки не менее 32 символов, например `openssl rand -hex 32`.

Настройка номера WhatsApp выполняется в `wrangler.toml` в блоке `[vars]`:

```toml
MONTHLY_PRICE_RUB = "299"
LIFETIME_PRICE_RUB = "2990"
WHATSAPP_NUMBER = "" # Например 79001234567, без знака плюса
SUPPORT_CALL_NUMBER = "" # Можно оставить пустым, для звонка будет тот же номер
```

Пока `WHATSAPP_NUMBER` пустой, кнопка WhatsApp **отключена**, а приложение сообщает, что контакты ещё не настроены. Изменение номера или цен требует только `npx wrangler deploy`, пересобирать APK не нужно.

## Сборка Android

Для подключённого сервера передавать адрес Cloudflare и публичный DER SPKI ключ при сборке:

```bash
gradle assembleRelease \
  -PceilingLicenseUrl=https://ACTUAL_ACCOUNT.workers.dev \
  -PceilingLicensePublicKeyB64=PUBLIC_BASE64_SPKI
```

**Сборка без этих параметров не является коммерческой**: для совместимости с существующими владельцами v224 работает бесплатный режим.

## API

Общедоступные:
- `GET /health`
- `GET /v1/catalog` — номера WhatsApp/звонка и цены в RUB, без банковских реквизитов.
- `POST /v1/auth/register` — автоматически стартует уникальный по аккаунту 7-дневный trial.
- `POST /v1/auth/recover` — восстанавливает лицензию по секретному коду клиента.
- `POST /v1/license` — выдаёт подписанную лицензию после восстановления или оплаты.

Административные, доступные только с заголовком `X-Admin-Key`:
- `GET /v1/admin/customer?user_id=UUID` — текущий статус клиента, срок и история лицензий.
- `POST /v1/admin/grants` — `{"user_id":"UUID","kind":"monthly","external_ref":"bank_transfer_001","period_days":30}`.
- `POST /v1/admin/grants` — `{"user_id":"UUID","kind":"lifetime","external_ref":"bank_transfer_002"}`.
- `POST /v1/admin/revoke` — `{"external_ref":"bank_transfer_001"}`, отзыв лицензии при законном основании.

Владелец также может управлять лицензиями в браузере на `https://YOUR_WORKERS_HOST/admin`; ключ не сохраняется на серверной странице и не вставляется в ссылку.

## Безопасность и ограничения

- Пробный срок сервером отсчитывается от первой регистрации, но **без подтверждения личности** повторный trial после удаления данных/новой регистрации полностью исключить нельзя.
- Подписанная offline-лицензия действительна максимум 14 дней без обновления, но не дольше конца триала/месячной покупки.
- Нельзя подтверждать перевод только по скриншоту. Проверять фактическое поступление в банковском приложении; при споре сохранять идентификатор операции.
- Режим владельца доступен в APK, но **только длинный секретный ключ, который не сохраняется в APK**, позволяет менять права на сервере. Секрет нельзя передавать клиентам.
- Если клиент потеряет секретный код восстановления, доступ на новом телефоне нельзя гарантировать без отдельной процедуры переноса.
- Физический владелец аккаунта/счёта должен законно получать оплату. Перед регулярными продажами определить продавца, налоговый режим, порядок чеков и условия продажи лицензий. Переводы на личную карту не отменяют эти обязательства.
- Никакие чертежи и сохранённые замеры не удаляются при истечении лицензии.
- До коммерческого запуска протестировать доступность сервера в России, собрать APK, проверить реальное восстановление, продление и отсутствие регрессий в чертежах v224.
