# Продажа «Замера потолка» через lava.top — разовые платежи

Эта схема **ещё не запущена**: нужны подтверждённый аккаунт продавца, реальные ссылки продуктов, Cloudflare Worker + D1 и успешный APK-билд.

## Почему так

Покупатель платит обычной российской картой или через СБП. Устанавливает нативное приложение и получает право использовать его 30 дней или бессрочно. Никаких автосписаний нет. После истечения 30 дней человек при желании покупает ещё один 30-дневный доступ.

**Электронная почта:** у приложения нет регистрации по email и своего почтового сервиса. Однако lava.top при первой покупке может требовать **email покупателя на самой платёжной странице** для учёта покупки. Не обещайте полностью без-email оформление у lava.top. См. https://faq.lava.top/article/59251.

## Сначала проверить право продажи и получение денег

Платёжный аккаунт должен принадлежать действительному продавцу. Он проходит проверку личности, использует разрешённые платёжные реквизиты и самостоятельно учитывает доход. Если продаёт лицензии, права на их продажу должны быть оформлены с правообладателем приложения. Нельзя регистрировать человека формально лишь для обхода ограничений на счётах.

До публикации спросить поддержку lava.top (support@lava.top):
- Можем ли мы продавать два **разовых цифровых продукта**, которыми является лицензия для отдельной нативной программы Android без автопродления?
- Допустима ли продажа такого товара конкретным типом вашего зарегистрированного аккаунта, с учётом местных законов?
- Какие способы и лимиты рублёвого вывода будут доступны на подтверждённые реквизиты владельца аккаунта?

В документации lava.top запрещены взломанное ПО и пиратские ключи; обычное авторское ПО там прямо не перечислено в этом запрете, но **проверка конкретного товара обязательна**.
Официальные правила: https://faq.lava.top/article/68568

## Публикация продуктов

1. Войти в https://lava.top под аккаунтом реального продавца.
2. Создать товар «Цифровой продукт», **не** «Подписка».
3. Первый продукт: **«Замер потолка PRO — 30 дней»**, **299 ₽**.
4. Второй продукт: **«Замер потолка PRO — бессрочно»**, **2 990 ₽**.
5. Для каждого товара в платном содержимом дать инструкции: скачать бесплатное APK из официального источника, открыть «Лицензия», начать бесплатный период, затем сообщить номер оплаченного заказа в разделе «Купить лицензию» или передать продавцу только публичный ID покупателя. После проверки платежа продавец подтверждает активацию.
6. Включить рублёвые платежи и СБП, если доступны аккаунту. Отправить продукты на модерацию и дождаться разрешения на вывод.
7. Скопировать **свои настоящие** ссылки этих двух продуктов в рублях. Ничего не подставлять наугад. Инструкция: https://faq.lava.top/article/79615.

## Подключение ссылок на Cloudflare

В `license-cloudflare/wrangler.toml` предусмотрены открытые переменные:

```toml
[vars]
MONTHLY_PRICE_RUB = "299"
LIFETIME_PRICE_RUB = "2990"
PAYMENT_MONTH_URL = ""
PAYMENT_LIFETIME_URL = ""
```

После создания товаров заменить пустые строки на реальные `https://lava.top/...` ссылки.
Можно указать ссылки `boosty.to` как резерв, если платформа будет подтверждена.
Секретные API-ключи для этого этапа не нужны.
После замены выполнить `npx wrangler deploy`.

APK получает эти ссылки по `GET /v1/catalog`; его не придётся пересобирать при изменении ссылок.

## Покупатель

1. Установить и запустить APK.
2. Открыть раздел «Лицензия» и нажать «Начать 7 дней бесплатно».
3. Сохранить секретный **код восстановления**. Его нельзя сообщать продавцу.
4. Нажать «Купить на 30 дней или навсегда», выбрать товар.
5. Перейти на настоящий сайт lava.top через обычный браузер и оплатить российской картой или СБП.
6. После оплаты вернуться в APK и передать номер заказа и тип покупки на проверку. **Это лишь заявка; доступ не выдаётся по её отправке.**
7. Когда продавец подтвердит покупку, нажать «Обновить лицензию». Интернет нужен лишь для активации; дальше подписанная лицензия работает офлайн в пределах доступного срока.

Если покупатель не находит номер заказа, он может отправить продавцу только **ID покупателя** из приложения. Продавец может активировать лицензию вручную через панель. Секретный код восстановления не передавать.

## Продавец с телефона

После размещения Cloudflare Workers в браузере открыть `https://<actual-subdomain>.workers.dev/admin`.

1. Ввести свой `ADMIN_API_KEY` из защищённого хранилища. Ключ не сохраняется на сайте.
2. Нажать «Загрузить заявки».
3. Проверить реальное зачисление по номеру заказа в lava.top и сверить вид товара.
4. Только после этого нажать «Подтвердить оплату». База выдаст доступ автоматически.

Дополнительный раздел «Выдать лицензию вручную» позволяет ввести ID покупателя и уникальный оплаченный заказ. Для месячной покупки Worker продлевает срок ещё на 30 дней от текущей оплаченной даты (или от текущей даты, если предыдущий доступ закончился). Бессрочную покупку записывает навсегда.

## Безопасность

- Пользовательский номер заказа **не** является доказательством оплаты. Не подтверждать без проверки в кабинете платёжного сервиса.
- Не включать автоматическое предоставление прав по `?status=success`, скриншотам или сообщениям от покупателя.
- Возвраты и чарджбэки проверять в lava.top; при необходимости вручную отзывать соответствующую лицензию (`POST /v1/admin/revoke`).
- Никогда не раскрывать `ADMIN_API_KEY` и RSA приватный ключ.
- Ограничить доступ к административному ключу, включить Cloudflare защиту от перебора и делать резервные копии D1.
- Реальные выплаты происходят только через правила продавца и платёжной платформы, не через Cloudflare.
